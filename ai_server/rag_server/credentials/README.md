# GCP TTS 서비스 계정 키 파일을 이 폴더에 배치하세요
# 
# 사용법:
# 1. GCP Console에서 서비스 계정 키 JSON 파일 다운로드
# 2. 이 폴더에 파일 복사 (예: gcp-tts-key.json)
# 3. .env 파일에 경로 설정:
#    GCP_TTS_CREDENTIALS_PATH=credentials/gcp-tts-key.json
#
# ⚠️ 보안 주의사항:
# - 이 폴더의 파일은 .gitignore에 포함되어 Git에 커밋되지 않습니다
# - 실제 서버에서는 환경 변수나 시크릿 관리 시스템 사용 권장
