# [FE] 대시보드 와이어프레임 작업 (S13P31A407-142)

## 작업 목적
관리자용 대시보드의 **화면 구조 초안(Wireframe)** 을 설계하고,  
페이지 내 **정보 배치**, **위젯 영역**, **통계 카드 레이아웃**을 구조화하기 위함.

## 작업 내용
- **Figma**를 활용해 그레이스케일 와이어프레임 제작  
- 주요 섹션 구성  
  - **헤더:** 회사명, 관리자 정보  
  - **사이드바:** 홈, 직원관리, 통신화면 메뉴  
  - **메인영역:** 근태현황, 장비사용률, 요청상태비율, 최근 요청 목록  
- **1440px** 기준으로 레이아웃 스페이싱 및 컴포넌트 간격 정리
